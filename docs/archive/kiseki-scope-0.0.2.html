1. Executive Summary & Core Concept

Kiseki (ιαπωνικά: 奇跡 – θαύμα / μικρή καθημερινή υπέρβαση) είναι μια micro-mindfulness mobile εφαρμογή σχεδιασμένη ως αντίδοτο στο Imposter Syndrome και το burnout. Αντί για ψυχρά checkboxes και τιμωρητικά streaks, η εφαρμογή μετατρέπει τις μικρές καθημερινές νίκες του χρήστη σε συλλεκτικά ψηφιακά αντικείμενα (origami stars / glowing gems) που πέφτουν και συσσωρεύονται μέσα σε ένα φυσικό 2D γυάλινο βάζο.

The Emotional Loop

  1. The Drop (Καταγραφή): Μία σύντομη σκέψη (≤ 180 χαρακτήρες) → μετατροπή σε origami star → ρεαλιστική πτώση με Matter.js → ήχος kalimba (pentatonic) + haptic feedback.
  2. The Shake (Ανάκτηση): Σε στιγμές απογοήτευσης ή αμφιβολίας → ανακίνηση της συσκευής (accelerometer, ≥ 2.5g για 2 συνεχόμενα δείγματα εντός 300 ms) → τα αστέρια ανακατεύονται → ένα αστέρι αναπηδά και αποκαλύπτει μια παρελθοντική νίκη.
  3. The Monthly Wrapped (Ικανοποίηση & Viral Loop): Στο τέλος κάθε μήνα παραγωγή aesthetic 9:16 κάρτας (1080×1920 px) για Instagram Stories / TikTok με στατιστικά και αναμνήσεις.

5. Physics Engine Specification (Matter.js)

5.1. Physics World Parameters

Για μια ικανοποιητική, παιχνιδιάρικη αλλά ήρεμη φυσική αίσθηση, οι παράμετροι βαθμονομούνται ως εξής:

  • Gravity: engine.gravity.y = 0.6 (default scale 0.001). Ελαφρώς χαμηλότερα από το standard Earth gravity του Matter (1.0) για floating, gentle descent. [TUNE] στόχος: χρόνος πτώσης lip→base ≈ 1.2–1.8 s στα 60 fps.
  • Engine Iterations: positionIterations: 6, velocityIterations: 4.
  • Sleeping Bodies: enableSleeping: true (κρίσιμο για μπαταρία: τα σώματα σε ηρεμία σταματούν τους υπολογισμούς έως ότου διαταραχθούν). sleepThreshold: 60 (default).

5.2. Container Boundary Geometry

Το βάζο αποτελείται από στατικά Matter.js bodies που σχηματίζουν container με ανοιχτό πάνω μέρος:

// src/components/canvas/physicsBounds.ts
import Matter from 'matter-js';

export function createJarBoundaries(width: number, height: number) {
  const wallThickness = 60;
  const jarWidth = Math.min(width * 0.88, 380);
  const jarHeight = height * 0.65;
  const bottomY = height * 0.85;
  const centerX = width / 2;
  const leftX = centerX - jarWidth / 2;
  const rightX = centerX + jarWidth / 2;
  const topY = bottomY - jarHeight;

  const wallOptions: Matter.IBodyDefinition = {
    isStatic: true,
    render: { visible: false }, // Rendered via SVG overlay
    friction: 0.2,
    restitution: 0.15
  };

  const floor = Matter.Bodies.rectangle(centerX, bottomY + wallThickness / 2, jarWidth, wallThickness, wallOptions);
  const leftWall = Matter.Bodies.rectangle(leftX - wallThickness / 2, bottomY - jarHeight / 2, wallThickness, jarHeight, wallOptions);
  const rightWall = Matter.Bodies.rectangle(rightX + wallThickness / 2, bottomY - jarHeight / 2, wallThickness, jarHeight, wallOptions);

  // Funnel neck bumpers (angled barriers at top, 30 degrees)
  const neckAngle = Math.PI / 6;
  const neckLength = 80;
  const leftNeck = Matter.Bodies.rectangle(leftX + 15, topY, neckLength, wallThickness, { ...wallOptions, angle: -neckAngle });
  const rightNeck = Matter.Bodies.rectangle(rightX - 15, topY, neckLength, wallThickness, { ...wallOptions, angle: neckAngle });

  return [floor, leftWall, rightWall, leftNeck, rightNeck];
}

5.3. Star Rigid-Body Properties

Κάθε αστέρι είναι ένα κανονικό πεντάγωνο (convex) με chamfered vertices — convex σχήμα για αποφυγή solver-jitter κατά το stacking:

  • Shape: Matter.Bodies.polygon(x, y, 5, STAR_RADIUS) με STAR_RADIUS = 12 px.
  • Chamfer: chamfer: { radius: 2 }.
  • Density: 0.0012 (ελαφρώς πιο «βαρύ» από default 0.001 για ήρεμο settle).
  • Friction: 0.08 (χαμηλό → τα αστέρια γλιστρούν σε piles).
  • FrictionStatic: 0.25 · FrictionAir: 0.012.
  • Restitution (Bounciness): 0.18 (ελαφρύ, όχι τρελό αναπήδημα).
  • Collision Filter: όλα τα αστέρια μοιράζονται category 0x0001 και συγκρούονται με τοίχους & μεταξύ τους (mask: 0xFFFFFFFF).
const STAR_RADIUS = 12; // px
const star = Matter.Bodies.polygon(x, y, 5, STAR_RADIUS, {
  density: 0.0012,
  friction: 0.08,
  frictionStatic: 0.25,
  frictionAir: 0.012,
  restitution: 0.18,
  chamfer: { radius: 2 },
  collisionFilter: { category: 0x0001, mask: 0xFFFFFFFF },
  render: { visible: false } // custom canvas drawing (Sprint 2)
});

5.4. Physics State Persistence & Restore Policy [REV 2 — fixed]

Γνωστός κίνδυνος (αφαιρέθηκε στο rev 2): η αναπαραγωγή σωμάτων ταυτόχρονα στις αποθηκευμένες συντεταγμένες προκαλεί επικαλύψεις → ο solver «εκρήγνυται». Η σωστή πολιτική είναι:
  • Cold start: τα αστέρια δεν τοποθετούνται στις αποθηκευμένες θέσεις. Επαναδημιουργούνται ένα-ένα από το στόμιο του βάζου (y = topY, x = center ± jitter ≤ 20% του jarWidth), με stagger 100 ms μεταξύ τους.
  • Το engine τρέχει έως ότου όλα τα σώματα κοιμηθούν (isSleeping === true) + 2 s idle timeout.
  • Κατά το restore απενεργοποιούνται τα chimes και ο ήχος (silent settle).
  • Persistence: όταν το world φτάσει σε steady state, αποθηκεύονται κάθε 1 s (throttled) τα lastX / lastY (normalized στο jar — range [0..1]) και rotation.
  • Τα αποθηκευμένα lastX/lastY χρησιμοποιούνται μόνο ως «target seat» (offset +2 px πάνω) για οπτική συνέχεια — ποτέ ως ταυτόχρονο spawn.

FR-2: The Shake & Recall Ritual (Anti-Imposter Engine)

  • Sensory Trigger (Accelerometer) — @capacitor/motion / DeviceMotionEvent:
    • Magnitude: mag = sqrt(aX² + aY² + aZ²), normalized σε g.
    • Trigger αν mag ≥ 2.5g για 2 συνεχόμενα δείγματα εντός 300 ms.
    • Debounce 1.5 s μεταξύ shakes.
  • Web Fallback: on-screen φυσικό «Shake the Jar» button.
  • Physics Reaction: εφαρμογή instant upward + τυχαίο lateral impulse σε όλα τα δυναμικά σώματα στο βάζο: 
    Matter.Body.setVelocity(body, { x: (Math.random()*2-1)*4, y: -(3 + Math.random()*3.5) });
  • Haptics & Audio: Haptics.notification({ type: NotificationType.Success }) + jar_shake.mp3.
  • Star Selection Algorithm (weighted random από IndexedDB):
    • isFavorite === true: weight 2.5
    • Δημιουργήθηκαν ≥ 3 ημέρες πριν: weight 2.0
    • Δημιουργήθηκαν < 24 ώρες πριν: weight 0.5 (προτεραιότητα σε μακρινές αναμνήσεις)
    • Συμπλήρωση σε ελάχιστο weight 0.1 (κανένα αστέρι με μηδενική πιθανότητα).
  • Reveal Sequence (RevealStarModal.tsx):
    1. Το επιλεγμένο αστέρι τονίζεται με έντονο radial glow στο canvas.
    2. Ανεβαίνει πάνω από το χείλος του βάζου και μεγαλώνει σε full screen.
    3. Ξεδιπλώνεται σε paper format: πλήρες κείμενο, σχετικό date badge («Πριν 2 μήνες, στις 14 Οκτωβρίου»), category badge, heart icon για isFavorite.
    4. Audio: resonant ambient bowl / kalimba chord.

FR-4: Soundscape Engine (Procedural Pentatonic Audio)

Για να αποφευχθεί το audio fatigue, δεν χρησιμοποιούνται repetitive pre-baked chimes. Οι συγκρούσεις αστεριών παράγουν νότες από την Eastern Pentatonic scale (C4, D4, E4, G4, A4):

// src/hooks/useSoundEffects.ts
const PENTATONIC_FREQUENCIES = [261.63, 293.66, 329.63, 392.00, 440.00];

export function playPentatonicChime(audioCtx: AudioContext, noteIndex: number, volume = 0.5) {
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  const freq = PENTATONIC_FREQUENCIES[noteIndex % PENTATONIC_FREQUENCIES.length];
  osc.type = 'sine';
  osc.frequency.setValueAtTime(freq, audioCtx.currentTime);
  // Gentle bell envelope (fast attack, exponential decay)
  gain.gain.setValueAtTime(0, audioCtx.currentTime);
  gain.gain.linearRampToValueAtTime(volume * 0.4, audioCtx.currentTime + 0.015);
  gain.gain.exponentialRampToValueAtTime(0.0001, audioCtx.currentTime + 1.2);
  osc.connect(gain);
  gain.connect(audioCtx.destination);
  osc.start();
  osc.stop(audioCtx.currentTime + 1.25);
}

Σημείωση: iOS απαιτεί user gesture για unlock του AudioContext — όλα τα triggers γίνονται μετά από tap (OK). Ορίστε cooldown 150 ms ανά σώμα στο collision handler (βλ. FR-1).

9. Performance & Mobile Battery Safeguards

  1. Matter.js Dynamic Throttle: όταν το canvas είναι σε steady-state (όλα τα σώματα sleeping via body.isSleeping === true), το Matter.Runner loop διακόπτεται πλήρως. Ξυπνά μόνο σε:
    • New star drop (τρέχει 4 s έως ότου ηρεμήσει).
    • Shake event (τρέχει 6 s έως ότου settled).
    • Orientation change / device tilt.
  2. Capacitor Motion Listener Throttling: το accelerometer listener δεν μένει ενεργό συνεχώς στο background. Επισυνάπτεται μόνο όταν η κύρια οθόνη Jar είναι active στο viewport και αφαιρείται όταν είναι ανοιχτά modals / wrapped cards / settings.
  3. Canvas Body Caps: μέγιστα δυναμικά σώματα ταυτόχρονα: 50. Αν το βάζο ξεπεράσει τα 50 αστέρια, τα bottom-most 10 μετατρέπονται σε ένα ενιαίο static aggregate base polygon → τα ενεργά δυναμικά pairs μειώνονται από n(n−1)/2 σε (n−k)(n−k−1)/2 (k=10): π.χ. n=50 → 1225 → 780 pairs. Επιπλέον, το sleeping το μειώνει περαιτέρω σε σχεδόν μηδέν στο steady state.
  4. Persistence throttle: αποθήκευση lastX/lastY/rotation μόνο στο steady state, κάθε 1 s (§5.4).
